# TTH Manager

TTH Manager is a software platform developed around the real operational
needs of Tales & Tech Hub.

The application centralizes the management of educational activities,
participants, enrollments, attendance, payments and related workflows.

## Overview

The project started from the need to replace multiple separate
administrative workflows with a single application.

It evolved into a complete software product used within the educational
center and became the foundation of my Bachelor's project in Computer Science.

## Features

- Participant management
- Workshop series management
- Scheduled workshops
- Enrollments
- Attendance tracking
- Payment cycles
- Demo workshop management
- Parent-facing workflows
- Real-time data updates
- Responsive cross-platform interface

## Tech Stack

- Flutter
- Dart
- Supabase
- PostgreSQL
- Real-time database functionality
- REST/API integrations
- Git & GitHub

## Architecture

TTH Manager is a cross-platform application built around a relational
data model and real-time synchronization.

Core modules include:

- Participant management
- Workshop scheduling
- Enrollments
- Attendance tracking
- Payment cycles
- Demo workshops
- Parent-facing workflows
- Real-time synchronization

## Privacy

The application is used in a real educational environment.

Screenshots containing production data are intentionally not published
in order to protect user privacy. Any visual examples included in this
repository use fictional demo data.

## Real-World Use

Unlike a purely academic project, TTH Manager was developed around an
actual operational need.

The system is designed to support daily administrative workflows at
Tales & Tech Hub.
